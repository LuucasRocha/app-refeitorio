# app-refeitorio

Caso de Uso: App de Refeitório

O sistema permite que o usuário faça um pedido de comida, especificando o item e a quantidade desejada. O pedido é colocado em uma fila e processado para verificar se o item está disponível no cardápio. Se o item existir e a quantidade for válida, o sistema calcula o valor total a ser pago. Caso contrário, retorna um erro.
